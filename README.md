# 📱 Mersal — Flutter Mobile App

Flutter mobile app for the Ovoo/Mersal platform with WhatsApp chat features, agent forms, and full Arabic RTL support.

## Features

- **Chat & Media** — WhatsApp-style chat with media support
- **Agent Forms** — in-app agent onboarding and configuration
- **Arabic Support** — full RTL layout and Arabic wording
- **Multi-language** — language switching support
- **Play Store Ready** — versioned builds (2.0.0+5)

## Tech Stack

- **Framework:** Flutter / Dart
- **Platform:** Android, iOS

## Build

```bash
flutter pub get
flutter run
# For release:
flutter build apk --release
```
